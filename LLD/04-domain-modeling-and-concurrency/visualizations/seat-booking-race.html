Takeaway: if (seat.isFree()) seat.book(me) is two steps. Without a guard, both threads pass the isFree() check before either books — and the seat is sold twice. compareAndSet(FREE, me) makes check-and-book a single atomic step: exactly one thread wins. Shared mutable state needs a guard.
