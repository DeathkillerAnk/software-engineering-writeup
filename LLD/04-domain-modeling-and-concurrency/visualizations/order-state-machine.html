Order state machine — illegal states are unreachable

LLD · 04 — try the transitions. A valid one advances the order; an invalid one is rejected by the model itself.

Takeaway: the order's methods guard their own invariants. collect() on a NEW order can't succeed — there's no path for it. Compare with scattering if (status == ...) checks across a dozen call sites: here the rule lives in one place, and the wrong transition is simply impossible.
