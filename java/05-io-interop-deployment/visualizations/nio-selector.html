NIO Selector — one thread, many connections

A selector blocks once and wakes only for the ready channels — so one thread serves thousands, vs a thread parked per connection. ← Part 5 · I/O, Interop & Deployment

What to notice: the selector thread only touches ready channels; the thousands of idle ones cost almost nothing. Thread-per-connection pays for every idle socket.
