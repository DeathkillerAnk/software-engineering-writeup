Isolation Anomalies & MVCC

Two concurrent transactions (T1, T2) operate on the same rows. Step through each operation to see how Lost Update and Write Skew arise — and watch how Snapshot Isolation and Serializable change the outcome. Key subtlety: snapshot isolation stops lost updates but still allows write skew.

Try this

Run Write Skew under Snapshot isolation, then under Serializable. Snapshot lets both doctors go off-call (invariant broken!) because they wrote different rows and never saw each other's write. Serializable detects the read/write dependency cycle and aborts T2. That gap is the whole point of SSI.
