Load Balancing Algorithms

Requests with random durations stream into a pool of servers. Each bar's height is that server's current in-flight load. Switch algorithms and watch how evenly (or unevenly) the load spreads. Power-of-Two-Choices samples two servers and picks the lighter one, getting near-perfect balance without any global coordinator.
