Consistent Hashing

Keys and servers both live on a circular hash ring. Each key is owned by the next server clockwise. When you add or remove a server, only the keys in one slice of the ring move — roughly 1/N of them — instead of nearly all keys, as plain hash(key) % N would force.

Ready. Press Play to watch a server join, or use Add / Remove node.

Try this: Set vnodes to 1 and watch how lopsided the colored arcs become — one server can own a huge slice. Now bump vnodes up to 24: the arcs even out. Then hit Add node and watch the “keys remapped” number stay near 1/N, then click Show naive mod-N to see almost every key turn amber.
