Bloom Filter

A Bloom filter is a tiny bit array plus k hash functions. Inserting an item flips k bits to 1. A query reports definitely not present if any of its bits is 0, or probably present if all are 1 — so false positives can happen, but false negatives never can.

Legend

  • Dark cell = bit is 0 (unset)
  • Blue cell = bit is 1 (set by some inserted item)
  • Green pulse = bit just touched by an insert or a successful query (all bits 1 → probably present)
  • Red pulse = a queried bit found to be 0 → item is definitely not present
  • Amber outline = a query whose bits were all set by other items → false positive

Try this

Set k = 1 and insert just 3 or 4 words, then click “Demo false positive.” With few bits set it’s easy to find a never-inserted word whose single bit is already 1 — a false positive. Now raise k and add more items: the fill ratio climbs and so does the false-positive rate. There is a sweet spot for k; too many hashes fills the array too fast.
