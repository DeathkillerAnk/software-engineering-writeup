Quorum Reads & Writes (R + W > N)

Data is copied to N replicas. A write must be acknowledged by W of them; a read must gather answers from R of them. When R + W > N, the read set and the write set are forced to share at least one node — so every read sees the freshest value.

Narration

Pick R, W, N then press “Write value” followed by “Read value”.

Legend

Try this: Set N=5, W=3, R=3 (sum 6 > 5) and do a write then a read — an overlap node always turns green and the read is fresh. Now drop R to 2 (sum 5 = N): run several reads and watch some land entirely on the old nodes, returning a stale value. That single missing node is the whole point of R + W > N.
