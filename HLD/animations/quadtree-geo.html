Spatial Indexing: Quadtree

A quadtree adapts to your data: a cell splits into four quadrants whenever it holds more than the capacity, so crowded areas get fine cells and empty areas stay coarse. A "find nearby" query then touches only the few cells near the radius instead of scanning every point.

Click on the map to scatter points (drivers / restaurants). Watch dense areas split into smaller cells.

Legend

  • Point (driver / venue)
  • Point inside query radius
  • Point in a touched cell (checked, but rejected)
  • Quadtree cell boundary
  • Cell the query touches
  • Uniform grid (comparison)

Try this

Click many times in one corner to build a dense cluster, then a few clicks elsewhere. Notice the quadtree carves the cluster into tiny cells while leaving open space as one big cell. Now switch to Run nearby query and click near the cluster: only a handful of cells light up. Toggle Uniform-grid compare to see how a fixed grid is either too coarse over the cluster or wasteful over empty space.
